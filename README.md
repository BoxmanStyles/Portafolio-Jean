# JeanCode.dev - Portafolio Personal

Portafolio personal de Jean Michael Rodriguez Quezada, creado para presentar su perfil como tecnico en sistemas, sus proyectos academicos, habilidades, certificados y datos de contacto profesional.

## Tecnologias

- React
- TypeScript
- Vite
- CSS

## Contenido

- Presentacion profesional basada en el CV
- Seccion de habilidades tecnicas y complementarias
- Proyectos escolares y portafolio personal
- Trayectoria academica en IPISA
- Certificados de Marketing Digital II e Introduction to Java
- Seccion de contacto con email, telefono y enlaces pendientes

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Notas

Los enlaces de GitHub, LinkedIn y demos de proyectos estan pendientes de actualizar cuando esten disponibles.
